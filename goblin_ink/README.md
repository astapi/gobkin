# ゴブリンキングダムRPGバトルシステム

DQ形式のターン制コマンドバトルシステム（TypeScript実装）

## 概要

- 4人PT（ゴブリン軍）vs 3体敵（人間軍）のターン制バトル
- 物理攻撃、魔法攻撃、回復、防御、逃走コマンド実装
- 簡易AI実装（敵の行動パターン）
- 状態異常なし、クリティカルなし、命中判定なし

## インストール

```bash
npm install
```

## ビルド

```bash
npm run build
```

## 実行

```bash
npm start
```

または開発モード（ビルド＋実行）：

```bash
npm run dev
```

## ゲームの特徴

### コマンド
- **たたかう**: 通常の物理攻撃
- **スキル/まほう**: MP消費の特殊技能
- **ぼうぎょ**: 被ダメージ軽減（物理0.7倍、魔法0.85倍）
- **どうぐ**: アイテム使用（未実装）
- **にげる**: 戦闘からの逃走

### キャラクター

#### 味方パーティ
- ゴブリンA, B: 物理攻撃型
- シャーマンゴブリン: 回復魔法使用可能
- レンジャーゴブリン: 二連射スキル持ち

#### 敵パーティ
- 人間戦士（男女）: 斬り上げスキル、低HPで防御
- 人間魔法使い: ファイア魔法優先

### ダメージ計算

#### 物理攻撃
```
基礎 = max(1, ATK - DEF/2)
ダメージ = floor(基礎 * 乱数(0.95-1.05) * 防御補正)
```

#### 魔法攻撃
```
基礎 = max(1, MAG*1.2 - RES)
ダメージ = floor(基礎 * 乱数(0.98-1.02) * 防御補正)
```
