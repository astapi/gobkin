# ゴブリンキングダムRPGバトル仕様書（DQ形式）

## 1. 概要

* 4人PT vs 敵3体の**ターン制コマンドバトル**
* **状態異常なし**
* **クリティカルなし**
* **命中判定なし（常に命中）**

---

## 2. パラメータ

| 名称        | 説明          |
| --------- | ----------- |
| HP / MP   | 体力 / 魔力     |
| ATK / DEF | 物理攻撃 / 物理防御 |
| MAG / RES | 魔法攻撃 / 魔法防御 |
| AGI       | 素早さ（行動順）    |

---

## 3. コマンド

* **たたかう**（物理攻撃 単体）
* **スキル/まほう**（攻撃 or 回復）
* **ぼうぎょ**（被ダメージ0.7倍）
* **どうぐ**（回復薬など）
* **にげる**（プレイヤーのみ）

---

## 4. ターン進行

1. **コマンド選択**（プレイヤーのみ）
2. **行動順決定**
   `AGI + 乱数(0〜AGI*0.1)` 降順
3. **行動解決**
4. **勝敗判定**（全滅／逃走成功）

---

## 5. 計算式

### 物理攻撃

```
基礎 = max(1, ATK - DEF/2)
乱数 = 0.95〜1.05
防御補正 = 0.7（相手がぼうぎょ中なら）
ダメージ = floor(基礎 * 乱数 * 防御補正)
```

### 魔法攻撃

```
基礎 = max(1, MAG*1.2 - RES)
乱数 = 0.98〜1.02
防御補正 = 0.85（相手がぼうぎょ中なら）
ダメージ = floor(基礎 * 乱数 * 防御補正)
```

### 回復（ヒール）

```
回復量 = floor(MAG*1.0 + 20) * 乱数(0.98〜1.02)
```

### 逃走

```
成功率 = clamp(0.35 + 0.15*(味方AGI合計 / 敵AGI合計), 0.35, 0.85)
```

---

## 6. AI（簡易）

* **戦士**

  * HPが30%以上 → たたかう／斬り上げ
  * HPが30%未満 → 25%の確率でぼうぎょ
* **魔法使い**

  * MP ≥ 6 → ファイア優先
  * MP < 6 → たたかう
