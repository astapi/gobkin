- 不滅の（HP +26-30%）

**魔法特化型（IV60, 4Mod）**:
- 大魔導の（SP +26-30%）
- 神霊の（SP +12-15）
- 壊滅の（ATK +26-30%）
- 不動の（被ダメ軽減 10-12%）

## 6. バランス調整ガイド

### Weight調整の目安

| 調整内容 | 効果 |
|----------|------|
| Weight × 2 | 出現率が約2倍に |
| Weight × 0.5 | 出現率が約半分に |
| Weight = 0 | そのModは出現しない |

### 効果量調整

- `valueRange` の範囲を変更することで効果量を調整
- Tier間のバランスを保つため、隣接Tierと重複しないよう注意
