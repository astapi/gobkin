### ギド（gido.png）— 古強者ゴブリン

- 群れで一番の年寄りゴブリン。小柄で痩せているが、筋張った腕と分厚い手。
- 白くなった眉毛とまばらな髭。片耳が欠けている（長年こき使われた古傷）。
- 武器は**拾い物の古い石斧**、反対の手に板を縛っただけの粗末な木盾。
- 表情は仏頂面。口を「へ」の字に曲げて悪態をつきそうな顔。ただし眼は鋭く、群れの誰よりも周囲を見ている。
- 役割はタンク（かばう・物理軽減）。姿勢はやや前傾で、誰かを背に庇うような立ち姿だとなお良い。
- 現行プレースホルダ: `goblin_guard_variant_b_heavy_tank.png`

### ラグ（ragu.png）— 疾風ゴブリン

- 若く小柄で身軽なゴブリン。体の線は細いが、日焼けして擦り傷だらけ。
- **ニカッと歯を見せて笑う**悪童顔。恐怖より好奇心が先に立つ性格が出るように。
- 片腕に添え木か包帯（初めて狼に乗って骨折した名残）。
- 狼の毛皮の襟巻きかベスト。武器は短めの槍か曲刀（騎乗で振れるもの）。
- 初代ウルフライダー。可能なら狼に騎乗した構図（既存 `goblin_rider.png` の後継になる）。前髪や襟巻きが風になびいていると「疾風」らしい。
- 現行プレースホルダ: `goblin_rider.png`

## 5. 画像追加時の実装手順

1. png を `assets/enemy/`（敵）または `assets/goblin/`（味方）に追加。
2. 敵: `src/shared/utils/enemyImages.ts` の `enemyImagesById` に **id をキーに**登録（名前キーはリネームで壊れるため使わない）。
3. 味方固有種: `src/shared/utils/goblinImages.ts` に登録し、`src/shared/data/namedGoblinSeeds.ts` の `avatar` パスを差し替え。
4. 優先順位の推奨: セクション1（味方2体）→ セクション2のうちストーリー登場ネームド（ロラン/グレアム/アレン）→ 出現頻度の高い序盤一般敵 → 残り。
