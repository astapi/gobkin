# 戦闘ステータスリファレンス

goblin_native の戦闘システムで使用されるステータスの仕様書。

## 用語定義

| 用語 | 意味 | 例 |
|---|---|---|
| 種族 | モンスターの大分類 | 魔獣、アンデッド、人間 |
| 血統 | ゴブリンの派生 | ゴブリン、スライムゴブリン、ウルフゴブリン、オークゴブリン、ホブゴブリン |

## コアステータス

| ステータス | 型 | 説明 |
|---|---|---|
| hp | number | ヒットポイント。0になると戦闘不能 |
| atk | number | 攻撃力。ダメージ計算の基礎値 |
| def | number | 防御力。被ダメージの軽減率に使用 |
| attackCount | number | 攻撃回数。1ターンに攻撃できる回数（血統基本値） |
| accuracy | number | 命中精度。命中率計算の攻撃側パラメータ |
| evasion | number | 回避能力。命中率計算の防御側パラメータ |

## 派生ステータス

| ステータス | 型 | 説明 |
|---|---|---|
| agility | number | 行動順決定に使う敏捷。ゴブリン/敵ともに基本能力値の敏捷を使う |
| damageReduction | number | 被ダメージ軽減率（0〜上限値%）。Modと装備から算出 |
| row | number | 隊列の行番号（0-based）。前列ほど狙われやすい |
| rowSlot | number | 行内のスロット番号（0-based） |

## 血統別攻撃回数補正

攻撃回数の血統差分だけが血統ごとの固定補正として残る。
`accuracy` と `evasion` は固定値ではなく、後述の基本能力値とLv依存式から算出する。

| 血統 | attackCount |
|---|---|
| ゴブリン | 2 |
| スライムゴブリン | 2 |
| ウルフゴブリン | 3 |
| オークゴブリン | 2 |
| ホブゴブリン | 2 |

### ゴブリン生成時の基礎値

基本能力値として `力 / 知恵 / 精神 / 体力 / 敏捷 / 運` を持つ。
誕生時は種族ごとの基準値から各能力値ごとに `-5〜+3` のランダム補正が入る。
レベルアップ時は各能力値が1レベルごとに+1され、種族ごとの最大値（種族基準値+10）に到達するとそれ以上は伸びない。

| 種族 | 力 | 知恵 | 精神 | 体力 | 敏捷 | 運 |
|---|---|---|---|---|---|---|
| ゴブリン | 10 | 10 | 10 | 10 | 10 | 10 |
| スライムゴブリン | 8 | 8 | 13 | 13 | 8 | 10 |
| ウルフゴブリン | 11 | 9 | 10 | 10 | 13 | 12 |
| ホブゴブリン | 13 | 11 | 11 | 11 | 11 | 10 |
| オークゴブリン | 15 | 8 | 9 | 15 | 7 | 8 |

HPはランダムではなく、体力とレベル依存式から決定される。

```
基礎HP = floor(体力 × (1 + Lv依存式 × 10 × 係数) + 1)
```

係数:

| 種族・ジョブ | 係数 |
|---|---|
| ゴブリン | 0.8 |
| スライムゴブリン | 1.2 |
| ウルフゴブリン | 0.9 |
| ホブゴブリン | 1.2 |
| オークゴブリン | 1.5 |
| ゴブリン（ガード） | 1.1 |
| ゴブリン（ウォリアー） | 1.2 |
| ゴブリン（シーフ） | 0.8 |
| ゴブリン（メイジ） | 0.7 |

Lv依存式:

| Lv | ゴブリン | ゴブリン以外 |
|---|---|---|
| 1〜30 | `Lv * 0.1` | `Lv * 0.1` |
| 31〜60 | `Lv * 0.15 - 1.5` | `Lv * 0.15 - 1.5` |
| 61〜80 | `Lv * 0.225 - 6` | `Lv * 0.225 - 6` |
| 81〜100 | `Lv * 0.225 - 6` | `Lv * 0.45 - 24` |
| 101〜150 | `Lv * 0.1125 + 5.25` | `Lv * 0.45 - 24` |
| 151〜180 | `Lv * 0.16875 - 3.1875` | `Lv * 0.45 - 24` |
| 181〜200 | `Lv * 0.253125 - 18.375` | `Lv * 0.45 - 24` |

HP以外の基礎ステータスは、以下の式で決定される。

```
基礎ATK = round(力 × (1 + Lv依存式 × 1 × 係数))
基礎命中精度 = round(((力 + 敏捷) / 2) × (1 + Lv依存式 × 2 × 係数) + 50)
基礎DEF = round(体力 × (1 + Lv依存式 × 1 × 係数))
基礎回避 = round(((敏捷 + 運) / 2) × (1 + Lv依存式 × 1 × 係数))
```

攻撃回数は敏捷ベースで計算する。

```
基本値 = (敏捷 / 10) × (1 + Lv依存式 × 0.025 × 係数) × 0.5
基本値1 = round(基本値 + 0.1)
基本値2 = round(基本値 - 0.3)
合計基本値 = max(1, 基本値1 + 基本値2)
基礎攻撃回数 = round(合計基本値 × 2)
```

- 行動順は `敏捷² × スキル補正 × 乱数B(0.21〜1.0)` で決定する

### ステータス算出まとめ

| 項目 | 基本式 | 丸め |
|---|---|---|
| HP | `体力 × (1 + Lv依存式 × 10 × 係数) + 1` | `floor` |
| ATK | `力 × (1 + Lv依存式 × 係数)` | `round` |
| DEF | `体力 × (1 + Lv依存式 × 係数)` | `round` |
| 命中精度 | `((力 + 敏捷) / 2) × (1 + Lv依存式 × 2 × 係数) + 50` | `round` |
| 回避 | `((敏捷 + 運) / 2) × (1 + Lv依存式 × 係数)` | `round` |
| 攻撃回数 | 上記の攻撃回数式 | 各段階で `round` |

### 能力値21以上の威力・耐性ボーナス

レベル成長、能力値スキル、装備MODを反映した最終能力値が20を超える場合、既存の装備・スキル補正とは別枠で以下を乗算する。指数に上限は設けない。

```text
物理与ダメージ倍率 = 1.04 ^ max(0, 力 - 20)
魔法与ダメージ倍率 = 1.04 ^ max(0, 知恵 - 20)
物理被ダメージ倍率 = 0.96 ^ max(0, 体力 - 20)
魔法被ダメージ倍率 = 0.96 ^ max(0, 精神 - 20)
```

例: 物理耐性5%と体力21を持つ場合、物理被ダメージ倍率は `0.95 × 0.96 = 0.912` となる。

## 行動順決定

### 基本式

```text
行動順値 = 敏捷² × スキル補正 × 乱数B
```

- ゴブリンの敏捷は `baseAttributes.agility` を使用
- 敵の敏捷も `baseAttributes.agility` を使用
- `乱数B` は `0.21〜1.0`
- 行動順値が高い順に行動
- 同値時は元の並び順 (`originalIndex`) を優先

### スキル補正

`actionOrderMultiplier` を持つスキルはすべて乗算で合算される。

| スキル | 倍率 |
|---|---|
| `[戦術] 高速行動` | `2.0` |
| `[戦術] 先制攻撃` | `1.5` |
| `[戦術] 待機攻撃` | `2/3` |
| `[戦術] 鈍足行動` | `1/2` |

### 例

```text
敏捷 = 10
スキル補正 = 1.5
乱数B = 1.0

行動順値 = 10² × 1.5 × 1.0 = 150
```

## ステータス計算

### 最終ステータスの算出

```
最終値 = (基礎 + 因子フラット + 装備フラット + スキルフラット) × (1 + 装備% / 100)
```

- `goblin.stats` は基礎ステータスを保持する
- 因子・装備・スキル補正は `GoblinStatCalculator` で合成する
- 行動順に使う敏捷は最終ステータスとは別管理

計算はGoblinStatCalculatorで行われ、以下の3つのソースから合算される:

1. **基礎ステータス** - レベルアップで成長する値（`goblin.stats`）
2. **因子ボーナス** - 獲得した因子（Factor）からのフラット加算
3. **装備・スキルボーナス** - フラット加算・%増加・倍率補正
| accuracy_flat | 命中精度 |
| evasion_flat | 回避能力 |
| damage_reduction | 被ダメージ軽減率 |

## ダメージ計算

### 基本式

```
damage = base × 防御軽減率 × 種族ボーナス × 被ダメ修正 × クリティカル × 乱数
```

### 各要素の詳細

| 要素 | 計算式 | デフォルト値 |
|---|---|---|
| base | `atk × skill.power` | 通常攻撃: power = 1.0 |
| 防御軽減率 | `1 - def / (def + defConstant)` | defConstant = 100 |
| 種族ボーナス | 攻撃側の装備・スキルによる種族特効 | 1.0 |
| 被ダメ修正 | 防御側の装備による種族耐性 | 1.0 |
| クリティカル | クリティカル発生時の倍率 | 1.5倍 |
| 乱数 | `min + random() × (max - min)` | 0.6〜1.05 |

### 被ダメージ軽減の適用

ダメージ計算後、さらに被ダメージ軽減率が適用される:

```
最終ダメージ = floor(計算ダメージ × (1 - damageReduction / 100))
最小ダメージ = 1
```

## 命中率計算

### 基本式

```
hitRate = accuracy × 命中補正(n) × 乱数A − evasion × HP補正 × 乱数B
→ clamp(5, 95)
```

- **命中補正(n)**: 攻撃回数による命中率低下（後述）
- **HP補正**: `0.5 × (1 + 現在HP / 最大HP)` — HPが減ると回避力が低下
- **乱数A, B**: それぞれ独立した乱数
- **下限5%、上限95%** に制限

## 攻撃回数による補正

1ターンに複数回攻撃する場合、回数が増えるほど威力と命中が低下する。

| 攻撃回数 | ダメージ補正 | 命中補正 |
|---|---|---|
| 1回目 | ×1.0 | ×1.0 |
| 2回目 | ×1.0 | ×0.6 |
| 3回目 | ×0.9 | ×0.54 |
| 4回目 | ×0.81 | ×0.486 |
| n回目 (n≥3) | ×0.9^(n-2) | ×0.6 × 0.9^(n-2) |

## 隊列システム

### 狙われ率の計算

敵は2D配列 `enemies[row][slot]` で配置され、前列ほど狙われやすい。

| 行 | 重み |
|---|---|
| 0（前列） | 1/2 |
| 1（中列） | 1/4 |
| 2（後列） | 1/8 |
| ... | 1/2^(n+1) |

※ 最後の2列は同率になる。

### ターゲット選択の流れ

1. 生存ユニットの列を前詰め
2. 列ごとの重みで抽選 → 対象の列を決定
3. 選ばれた列内でスロット順に重み付き抽選 → 対象ユニットを決定

## 戦闘フロー

1. **初期化**: Goblin/Enemy → BattleUnit に変換（実効ステータスを適用）
2. **ターンループ**（最大20ターン）:
   1. 生存ユニットごとに `行動順値 = 敏捷² × スキル補正 × 乱数B` を計算
   2. 行動順値の高い順にソート
   2. 各ユニットが attackCount 回攻撃:
      - 隊列を考慮してターゲット選択
      - 命中判定（accuracy vs evasion）
      - ヒット時: ダメージ計算 → 被ダメ軽減適用 → HP減少
      - ミス時: ログに missed を記録
   3. 全滅判定 → 勝敗が決まればループ終了
3. **結果生成**: 戦闘ログ、勝敗、HP変化量を返却
