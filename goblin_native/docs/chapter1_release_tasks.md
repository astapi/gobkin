# 第1章リリースタスク

## 目的

初期バージョンでは、遠征進行の `vs討伐軍` までを第1章のリリース対象とする。
このドキュメントでは、第1章として出すために必要なゲーム実装、バランス調整、多言語対応、ストア準備の作業を整理する。

## リリース範囲

- 対象進行: `vs討伐軍` まで
- 対象アプリ: `goblin_native`
- 主要判断基準:
  - 第1章内で仲間になる亜種、ジョブ、装備、スキルが一通り成立している
  - MODシステム廃止後の育成導線が、スキル継承として成立している
  - `vs討伐軍` までの難易度カーブが、想定パーティと代替パーティの両方で検証されている
  - ストア掲載に必要なタイトル、説明文、スクリーンショット、アイコン、スプラッシュが揃っている

## 1. ゲームシステム実装

### 1.1 MODシステム廃止とスキル継承の構築

| 項目 | 内容 |
|------|------|
| 現状 | MODシステムは誕生時ランダム付与のパッシブ効果として存在 |
| 作業内容 | MOD付与・表示・ステータス反映を廃止し、ゴブリン育成の軸をスキル継承へ移行する |
| 主な参照 | `docs/mod_system.md`, `docs/character_skills.md`, `docs/goblin_birth_system.md`, `docs/factor_system.md` |
| 完了条件 | 新規ゴブリン生成、詳細画面、戦闘計算、保存データでMOD依存が残っていない |

実装時に決めること:

- 継承可能なスキル種別
- 継承枠数
- 継承元の条件
- 継承率または選択式にするか
- 既存保存データにMODがある場合の扱い
- UI上の表示位置と編集導線

### 1.2 反撃回避スキルの実装

| 項目 | 内容 |
|------|------|
| 作業内容 | 反撃を受ける攻撃時に、一定条件で反撃を回避するスキルを追加する |
| 主な参照 | `docs/battle_system.md`, `docs/battle_system_spec.md`, `docs/character_skills.md` |
| 完了条件 | 反撃発生判定と回避判定の順序が明確で、戦闘ログから挙動を確認できる |

確認事項:

- 回避率を固定値にするか、スキルLvやステータスで変動させるか
- 全反撃に有効か、物理反撃のみ有効か
- 複数回攻撃時の判定単位

### 1.3 ローブ系統装備の実装

| 項目 | 内容 |
|------|------|
| 作業内容 | ローブ系統装備を追加し、魔法寄りビルドの防具選択肢を増やす |
| 主な参照 | `docs/drop_system.md`, `docs/battle_stats.md`, `docs/balance_reference.md` |
| 完了条件 | 装備データ、表示、ドロップ、ステータス反映、i18n表示が揃っている |

確認事項:

- ローブの基本ステータス配分
- 装備可能ジョブまたは種族制限の有無
- 既存防具との役割差
- ドロップ対象ダンジョン

### 1.4 `[x倍]シールド装備` と `[x倍]ローブ装備` の実装

| 項目 | 内容 |
|------|------|
| 作業内容 | シールド系・ローブ系に倍率付き装備効果を実装する |
| 主な参照 | `docs/drop_system.md`, `docs/battle_stats.md`, `docs/balance_reference.md` |
| 完了条件 | 倍率効果がステータス計算または戦闘計算へ反映され、UIで効果が判別できる |

確認事項:

- 倍率対象を防御、魔防、軽減、装備基礎値のどれにするか
- 既存装備称号との合算順
- 倍率上限
- レアリティやドロップ率

### 1.5 魔法保護の実装

| 項目 | 内容 |
|------|------|
| 効果 | 自身より後列にいるメンバーが受ける魔法ダメージを `2/3` にする |
| 作業内容 | 隊列を参照した魔法ダメージ軽減スキルを実装する |
| 主な参照 | `docs/battle_system.md`, `docs/battle_system_spec.md`, `docs/character_skills.md` |
| 完了条件 | 前列に保護役がいる場合のみ、後列メンバーの魔法ダメージが軽減される |

確認事項:

- 複数人が魔法保護を持つ場合の重複可否
- 範囲魔法に対する適用
- 本人への適用有無
- 魔法ダメージ軽減系スキルとの合算順

### 1.6 マジックフィールドの実装

| 項目 | 内容 |
|------|------|
| 効果 | 味方の魔法ダメージが `1.5倍` になる |
| 作業内容 | 味方全体の魔法攻撃に乗るフィールド系バフを実装する |
| 主な参照 | `docs/battle_system.md`, `docs/battle_system_spec.md`, `docs/character_skills.md` |
| 完了条件 | 味方の魔法ダメージのみが増加し、物理攻撃や敵側には影響しない |

確認事項:

- 常時パッシブか、発動型スキルか
- 複数持ちの重複可否
- 回復魔法に影響するか
- 魔法ダメージ倍率系との合算順

### 1.7 即時蘇生の実装

| 項目 | 内容 |
|------|------|
| 効果 | 味方が死亡したときに回復魔法を唱えて蘇生する |
| 作業内容 | 味方死亡イベントをトリガーにした自動蘇生スキルを実装する |
| 主な参照 | `docs/battle_system.md`, `docs/battle_system_spec.md`, `docs/character_skills.md` |
| 完了条件 | 死亡直後に条件を満たす味方が蘇生し、戦闘ログとHP状態が一致する |

確認事項:

- 1戦闘あたりの発動回数
- MPや詠唱者の行動済み状態を消費するか
- 複数人が持つ場合の発動優先順位
- 全体攻撃で詠唱者も同時に死亡した場合の扱い

### 1.8 ダンジョンTierによる敵スキルスケールの実装

| 項目 | 内容 |
|------|------|
| 作業内容 | ダンジョンTierに応じて敵スキル効果をスケールさせる |
| 対象例 | 物理ダメージ軽減、魔法ダメージ軽減など |
| 主な参照 | `docs/balance_reference.md`, `docs/expedition_system.md`, `docs/battle_system.md` |
| 完了条件 | 同一スキルでもダンジョンTierに応じて効果量が変わり、バランス検証で参照できる |

確認事項:

- Tierの取得元
- スケール対象スキル
- スケール式
- ボスと通常敵で差をつけるか
- 既存敵JSONへの持たせ方

## 3. バランス見直し

### 3.1 第1章全体の進行カーブ再検証

| 項目 | 内容 |
|------|------|
| 作業内容 | 亜種、ジョブ、装備、スキル継承を反映した状態で、`vs討伐軍` までの難易度を再検証する |
| 主な参照 | `docs/balance_reference.md` |
| 完了条件 | 各主要ダンジョンの推奨Lv、突破率、想定ロードアウトが記録されている |

検証対象:

- ゴブリン集落
- オーク野営地
- ウルフ草原
- リザードマンの沼砦
- オークの砦
- vs討伐軍

### 3.2 ロードアウト別の突破率検証

| 項目 | 内容 |
|------|------|
| 作業内容 | 複数の代表構成で第1章終盤までの突破率を比較する |
| 完了条件 | 強構成、標準構成、亜種なし構成、ジョブ中心構成の差が説明できる |

最低限見る構成:

- 亜種あり標準構成
- 亜種なしジョブ強化構成
- 魔法主体構成
- 防御・軽減主体構成
- 回復・蘇生主体構成

### 3.3 新規スキル追加後の再調整

| 項目 | 内容 |
|------|------|
| 作業内容 | 反撃回避、魔法保護、マジックフィールド、即時蘇生、敵スキルスケールを入れた後に再調整する |
| 完了条件 | 追加スキルによって特定構成だけが極端に有利になっていない |

重点確認:

- 反撃持ち敵への対策が必須になりすぎていないか
- 魔法構成が `1.5倍` バフで突出しすぎていないか
- 即時蘇生で長期戦が破綻していないか
- 敵の物理/魔法軽減がプレイヤーの選択肢を潰していないか
