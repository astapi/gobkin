戦闘 命中・回避・ターゲット選定 仕様書

通常攻撃まわりの命中判定、ダメージ補正、隊列ターゲット選定の現行ロジックを一式まとめた仕様書です。実装は src/core/services/BattleSystem.ts を正とします。

1. 1回の通常攻撃の流れ

攻撃ユニットの攻撃回数分だけループし、各ループで以下を実行します。

  1. 生存敵リストの取得（直前に攻撃した敵も再度候補に含まれる）
  2. ターゲット選定 — 列＋スロットの重み付きルーレット抽選
  3. 命中判定 — 命中精度・回避・残HP・攻撃番号から算出
  4. ダメージ計算 — 命中HIT番号によりダメージ減衰を適用
注意: ターゲットが変わっても「攻撃番号 atkIdx + 1」は累計でカウントされ、命中精度・ダメージの補正は引き継がれます。違う敵を狙っても1回目扱いには戻りません。

参照: BattleSystem.ts:656-731 executeBasicAttack

2. 命中判定

2.1 計算式

hitRate = clamp( rand × (attacker.accuracy × accMod − defender.evasion × hpMod), 5, 95 ) isHit = (rng() × 100) < hitRate

各要素の定義:

要素意味定義
rand 乱数係数 0.95 + rng() × 0.1 （0.95〜1.05）
accMod 攻撃番号による命中精度補正 1回目=1.0、2回目以降=0.6 × 0.9^(n−2)
hpMod 残HP補正（回避側） 0.5 × (1 + 残HP / 最大HP) （満血1.0／瀕死0.505）
クランプ 命中率の上下限 最小5% / 最大95%

参照: BattleSystem.ts:613 calculateHitRate, BattleSystem.ts:199 getAccuracyModifier

2.4 命中率の可視化

命中精度 = 1000、回避 = 100、満血の敵に攻撃したときの命中率カーブ。

命中精度と回避の差が 100以上 あるとクランプで95%に張り付き、攻撃回数補正が無効化されます（1回目・満血敵）。攻撃番号が大きくなるにつれ補正が効いて減衰しますが、この例では13発目までは95%に張り付きます。

違和感の正体: 高難度では命中精度が回避を大きく上回るため、攻撃回数を増やしても上限95%に貼り付いて全弾命中に近くなります。回避を高くするか、命中精度の上限を抑える設計バランスが必要です。

3. ダメージの攻撃回数補正

ダメージは「命中HIT番号」（ミスを含めない命中ヒットの累計番号）で減衰します。1〜2発目は満タン、3発目以降は0.9倍ずつ減衰。

dmgMod = (HIT番号 ≤ 2) ? 1.0 : 0.9^(HIT番号 − 2)

4. ターゲット選定（隊列・スロット）

4.1 抽選の手順

  1. 生存ユニットを「列」でグループ化
  2. 列を前詰めしてインデックス0,1,2…に振り直す
  3. 列のインデックスごとに重みを計算 → 重み付きルーレット抽選で列を選ぶ
  4. 選んだ列に複数いれば、列内スロットも同じ重みでルーレット抽選

参照: BattleSystem.ts:228 selectTarget, BattleSystem.ts:217 getRowWeight

4.2 列の重み（最新仕様）

row 0 (タンク列) → 13/12 ≒ 1.0833 row 1 (2列目) → 1/3 ≒ 0.3333 row n ≥ 2 → 0.5^(n+1) （最後2列は同率にクランプ）

列1（最前列タンク）と列2を特別重みで強化し、後列にはほぼ攻撃が届かない設計です。

4.7 重要な性質

  • 独立抽選 攻撃ごとに毎回独立してターゲットを選び直すため、同じ敵が連続で選ばれることもあります（除外なし）。
  • 前詰め 列の欠番は詰めて再計算するため、列1（タンク）が倒れると元・列2が新「列1」となり65%を吸い込みます。
  • 最後2列同率 列数によって最後の2列は同じ重みになります（囲まれた状態を表現）。
  • 2列攻撃スキル twoColumnAttack を持つ攻撃者は、メインターゲットの後ろの列にも追加攻撃します（命中判定は独立）。

6. まとめ

命中判定

  • 命中率は rand × (accuracy × accMod − evasion × hpMod) を 5%〜95% にクランプ。
  • 攻撃番号が増えるほど accMod が減衰（1.0 → 0.6 → 0.54 → …）。
  • 敵の残HPが少ないほど hpMod が下がり、回避が無力化される。
  • 命中精度と回避の差が大きすぎると上限95%に張り付き、攻撃回数補正が事実上無効化される（高難度バランス上の注意点）。

ダメージ補正

  • 命中HIT番号（ミスを除外したカウント）でダメージ減衰を適用。
  • 1〜2発目は100%、3発目以降は 0.9^(n−2)。

ターゲット選定

  • 列1=65%・列2=20% に集中させたタンク有利な分布。
  • 列3以降は 0.5^(n+1) で急減衰、後列は被弾ほぼなし。
  • 列が減ると前詰めで再計算 → 列1の重みは引き続き有効。
  • 攻撃ごとに独立抽選で、同じ敵が連続して選ばれることもある。
