# 装備MODシステム

## 概要

敵から通常ドロップする装備には、prefix MODを1個、suffix MODを1個付与する。
ショップ購入品と既存セーブ内の装備にはMODを後付けしない。

## 初期MODプール

- Prefix: 力、知恵、精神
- Suffix: 体力、敏捷、運

各MODはT10（最低）からT1（最高）までを持ち、初期値はT10が+1、T9が+2、以降1ずつ増えてT1が+10となる。

## 敵レベルとTier抽選

敵レベルは抽選可能な最高Tierを解禁する。解禁済みの最高TierからT10までをウェイト付きで抽選し、対象Tierのウェイト合計を基準に確率を再計算する。

| 敵レベル | 抽選可能な最高Tier |
| --- | --- |
| 1〜29 | T10 |
| 30〜44 | T9 |
| 45〜59 | T8 |
| 60〜74 | T7 |
| 75〜89 | T6 |
| 90〜104 | T5 |
| 105〜119 | T4 |
| 120〜134 | T3 |
| 135〜149 | T2 |
| 150以上 | T1 |

Lv150以上でも常にT1になるわけではなく、PoEのアイテムレベルと同様にT1が抽選候補へ入る。

### Tier抽選ウェイト

| Tier | ウェイト | 全Tier解禁時の確率 |
| --- | ---: | ---: |
| T1 | 1 | 0.47% |
| T2 | 4 | 1.90% |
| T3 | 10 | 4.74% |
| T4 | 40 | 18.96% |
| T5 | 40 | 18.96% |
| T6 | 36 | 17.06% |
| T7 | 30 | 14.22% |
| T8 | 24 | 11.37% |
| T9 | 16 | 7.58% |
| T10 | 10 | 4.74% |

例えばT7〜T10だけが解禁済みの場合は、合計ウェイト80を基準にT7が37.5%、T8が30%、T9が20%、T10が12.5%となる。Tierブーストは設けない。

## ダンジョンTierによる複数抽選

prefix・suffixごとにダンジョンTierに応じた回数だけTierを抽選し、その中で最も高いTierを採用する。称号はMOD Tierへ影響しない。

| ダンジョンTier | 抽選回数 | 全MOD Tier解禁時のT1確率 |
| --- | ---: | ---: |
| 0 | 1 | 0.47% |
| 1 | 2 | 0.95% |
| 2 | 4 | 1.88% |
| 3 | 7 | 3.27% |
| 4 | 12 | 5.54% |
| 5 | 25 | 11.20% |

敵レベルによるTier解禁範囲は各抽選へ適用される。例えばT1未解禁の敵からは、ダンジョンTierが高くてもT1は付与されない。

## インベントリ統合

次の4要素がすべて同じ未装備アイテムだけを同一スタックとして表示する。

1. 装備テンプレート
2. 称号
3. Prefix MODのIDとTier
4. Suffix MODのIDとTier

SQLite上では装備インスタンスを個別に保持し、画面表示時だけまとめる。

## 装備単位の自動売却フィルター

遠征で新たに獲得した装備は、装備テンプレートごとに次のいずれかを設定できる。

- 全部残す（未設定時の既定値）
- 全部売る
- 詳細設定

詳細設定では「残す条件」を複数登録する。同じ条件内の称号・prefix MOD・prefix Tier・suffix MOD・suffix TierはAND、条件同士はORで判定し、どの条件にも一致しなかった装備を自動売却する。未選択の項目は不問として扱う。

装備商店または倉庫で手動売却した後は、その個体と装備テンプレート・称号・prefix MOD/Tier・suffix MOD/Tierが完全一致する「売る条件」を追加できる。売る条件は残す条件より優先し、自動売却設定画面から装備単位で解除できる。

倉庫では名前・MOD数・カテゴリ・称号で絞り込んだ結果を一括売却できる。一括売却後は、対象となった装備テンプレートと選択中の称号・MOD数を「一括売却フィルター」として保存するか確認し、保存した条件は今後の遠征ドロップへ適用する。フィルター未設定時は全装備の誤売却を避けるため、一括売却を表示しない。

自動売却は遠征報酬の確定時だけ行い、既に所持している装備には適用しない。価格は装備商店での手動売却と同じく、`基礎価格 × 称号価格倍率 × 50%`（最低1G）とする。設定はSQLiteの`app_metadata`へ保存し、セーブデータの書き出し対象に含める。
