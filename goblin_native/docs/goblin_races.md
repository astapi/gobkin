# ゴブリン種族一覧

## 概要

ゴブリンには基本種族「ゴブリン」と、因子の引き継ぎによって誕生する9種類の亜種が存在する。
亜種は拠点の「群れを増やす」で固定した継承元とランダム選出個体から因子を引き継ぎ、最低＋値を満たしたうえで亜種化判定に成功した場合に産まれる。

## 誕生の仕組み

### 通常のゴブリン

「群れを増やす」で「開始」を押してから10分後に誕生する。継承元とランダム選出個体が因子を持たない場合は必ず通常のゴブリンになる。

### 亜種ゴブリンの誕生フロー

1. **継承元の設定**: プレイヤーが1体を固定し、もう1体を拠点からランダム選出（マルクだけなら単独）
2. **因子引き継ぎ判定**: 1〜2体が持つ各因子について、因子ごとの引き継ぎ確率で判定
3. **亜種化判定**: 子の＋値が最低条件を満たす因子について亜種化確率で判定（最初に成功した1種のみ適用）

つまり「設定個体が因子を持っている」→「引き継ぎ成功」→「最低＋値を満たす」→「亜種化成功」の4段階を突破する必要がある。

### 亜種化に必要な最低＋値

| 亜種 | 最低＋値 |
|------|---------:|
| スライム | 0 |
| ウルフ | 5 |
| オーク / アンデッド | 10 |
| ホブゴブリン | 15 |
| アイアン / フェイ | 20 |
| スカイ / スクラッパー | 25 |
| スケイル | 30 |
| トロル | 35 |
| ゴズ | 40 |
| ヴァンプ | 45 |
| ドラゴン / シャドウ | 50 |

## 種族一覧

### ゴブリン（基本種族）

| 項目 | 値 |
|------|-----|
| 攻撃回数 | 2 |
| 装備スロット | 基本2 / Lv5ごとに+1 / 最大6 |
| 産まれる条件 | デフォルト（亜種化しなかった場合） |

---

### スライムゴブリン

| 項目 | 値 |
|------|-----|
| 対応因子 | スライム因子 |
| 因子の引き継ぎ確率 | 30% |
| 亜種化確率 | 20% |
| 攻撃回数 | 2 |

**因子効果（引き継ぎ時に付与）:**
- HP +100

**種族スキル:**
- **[1.3倍]鎧装備**: 鎧カテゴリのアイテム装備時、その装備が持つ能力値補正・装備効果の数値が1.3倍になる。
- **後列防護**: 自分より後列にいる味方が受ける通常攻撃ダメージを 2/3 に軽減する。

**特徴:** HP特化の耐久型。

---

### ウルフゴブリン

| 項目 | 値 |
|------|-----|
| 対応因子 | ウルフ因子 |
| 因子の引き継ぎ確率 | 25% |
| 亜種化確率 | 15% |
| 攻撃回数 | **3**（唯一の3回攻撃） |

**因子効果（引き継ぎ時に付与）:**
- ATK +15

**種族スキル:**
- **[+2]攻撃回数アップ**: 攻撃回数 +2。
- **[2.0倍]命中精度**: 装備由来の命中精度補正（`accuracy_flat`）が2.0倍になる。
- **[+13]追加ダメージ**: 通常攻撃の各ヒットに固定で +13 ダメージを加算する。

**特徴:** 全種族中唯一の攻撃回数3回。速度と攻撃力に優れるアタッカー型。
