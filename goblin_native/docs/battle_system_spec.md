# 戦闘システム

## 概要

ターン制の自動戦闘。味方ゴブリンと敵がSPD順に行動し、通常攻撃または魔法で戦う。
最大20ターンで決着がつかない場合は撤退扱い。戦闘はシード値ベースで決定論的に再現可能。

## 戦闘の流れ

```
1. 初期化
   ├─ 味方: Goblin[] → BattleUnit[]（因子・Mod適用後のステータス使用）
   └─ 敵: Enemy[][] → BattleUnit[]（2D配列で隊列を指定）

2. ターンループ（最大20ターン）
   ├─ ターン10: 全生存ユニットの魔法チャージ+1回復
   ├─ 行動順決定: 全生存ユニットをSPD降順でソート
   └─ 各ユニットの行動:
       ├─ 魔法チャージあり → 魔法を使用（優先）
       └─ なし → 通常攻撃（attackCount回）
           ├─ ターゲット選択（隊列重み付き）
           ├─ 命中判定
           ├─ ダメージ計算 → 被ダメ軽減適用
           └─ HP減少
   ↓
3. 終了判定
   ├─ 敵全滅 → 勝利 (win)
   ├─ 味方全滅 → 敗北 (lose)
   └─ 20ターン到達 → 撤退 (retreat)
```

## ダメージ計算式

### 通常攻撃の基本ダメージ

```
baseDamage = max(1, floor(ATK × power × defMitigate × raceFactor × takenFactor × critFactor × rand))
```

| 要素 | 計算 | デフォルト値 |
|------|------|------------|
| power | スキル倍率 | 通常攻撃: 1.0 |
| defMitigate | `1 - DEF / (DEF + defConstant)` | defConstant = 100 |
| raceFactor | `(1 + 種族加算合計) × 種族乗算積` | 現在は1.0 |
| takenFactor | `(1 + 被種族加算合計) × 被種族乗算積` | 現在は1.0 |
| critFactor | クリティカル時の倍率 | rate=0, mult=1.5（実質未使用） |
| rand | 乱数補正 | 0.95〜1.05 |

### 防御軽減率の仕組み

```
defMitigate = 1 - DEF / (DEF + 100)
```

| DEF | 軽減率 | 実質ダメージ |
|-----|-------|------------|
| 10 | 9.1% | 90.9% |
| 25 | 20.0% | 80.0% |
| 50 | 33.3% | 66.7% |
| 100 | 50.0% | 50.0% |
| 200 | 66.7% | 33.3% |

DEFが高いほど軽減率は上がるが、100%には到達しない（漸近的）。

### 攻撃回数によるダメージ補正

複数回攻撃時、3回目以降はダメージが逓減する:

```
getDamageModifier(n):
  n ≤ 2 → 1.0
  n ≥ 3 → 0.9^(n-2)
```

| 攻撃回数 | 補正 |
|---------|------|
| 1回目 | ×1.0 |
| 2回目 | ×1.0 |
| 3回目 | ×0.9 |
| 4回目 | ×0.81 |
| 5回目 | ×0.729 |

### 被ダメージ軽減の適用

基本ダメージ算出後に適用される:

```
最終ダメージ = max(1, floor(baseDamage × dmgMod × (1 - damageReduction / 100)))
```

- `damageReduction` はModと装備の合算（上限75%）
- 最低ダメージは1（0にはならない）
- **敵は被ダメージ軽減を持たない**（常に0）

## 命中・回避システム

### 命中率の計算

```
hitRate = clamp(5, 95, rand × (accuracy × accMod - evasion × hpMod))
```

| 要素 | 説明 |
|------|------|
| rand | 0.0〜1.0 の乱数 |
| accuracy | 攻撃者の命中精度 |
| accMod | 攻撃回数による命中補正 |
| evasion | 防御者の回避能力 |
| hpMod | 防御者のHP残量補正 |

### 攻撃回数による命中補正

2回目以降の攻撃は命中率が大幅に低下する:

```
getAccuracyModifier(n):
  n = 1 → 1.0
  n ≥ 2 → 0.6 × 0.9^(n-2)
```

| 攻撃回数 | 補正 |
|---------|------|
| 1回目 | ×1.0 |
| 2回目 | ×0.6 |
| 3回目 | ×0.54 |
| 4回目 | ×0.486 |

### HP残量補正

防御者のHPが減っているほど回避しにくくなる:

```
hpMod = 0.5 × (1 + currentHP / maxHP)
```

| HP残量 | hpMod | 効果 |
|--------|-------|------|
| 100% | 1.0 | 回避力フル発揮 |
| 50% | 0.75 | 回避力75% |
| 0% | 0.5 | 回避力半減 |

### 命中判定

```
isHit = (rng() × 100) < hitRate
```

- 命中率の下限: **5%**（必ず5%は当たる可能性がある）
- 命中率の上限: **95%**（必ず5%は回避される可能性がある）

### 計算例

```
攻撃者: accuracy=150, 1回目の攻撃
防御者: evasion=20, HP 80/100

accMod = 1.0
hpMod  = 0.5 × (1 + 0.8) = 0.9
rand   = 0.7 (例)

hitRate = 0.7 × (150 × 1.0 - 20 × 0.9)
       = 0.7 × (150 - 18)
       = 0.7 × 132
       = 92.4%
→ clamp(5, 95) → 92.4%
```

## 隊列とターゲット選定

### 隊列の構造

**味方**: 1列1体。パーティ配列のインデックスがそのまま列番号（0が最前列）。

**敵**: 2D配列で指定。1列に複数体配置可能。

```
敵の例:
  列0（前列）: [ゴブリンA, ゴブリンB]
  列1（中列）: [オーク]
  列2（後列）: [ボス]
```

### ターゲット選択アルゴリズム

1. **列グループ化**: 生存ユニットを列番号でグループ化
2. **列の前詰め**: 生存列だけを前から連番化（列0,2,5 → 相対0,1,2）
3. **列の重み付き抽選**: 前列ほど狙われやすい
4. **列内のターゲット抽選**: rowSlot順で前ほど狙われやすい（同じ重み方式）

### 列の重み（getRowWeight）

```
重み = 0.5^(effectiveRow + 1)
※ 最後の2列は同率
```

| 生存列数 | 列0 | 列1 | 列2 | 列3 | 列4 | 列5 |
|---------|-----|-----|-----|-----|-----|-----|
| 1列 | 100% | - | - | - | - | - |
| 2列 | 50% | 50% | - | - | - | - |
| 3列 | 50% | 25% | 25% | - | - | - |
| 4列 | 50% | 25% | 12.5% | 12.5% | - | - |
| 6列 | 50% | 25% | 12.5% | 6.25% | 3.125% | 3.125% |

**前列が壊滅した場合**: 生存列が前詰めされるため、元・中列が新・最前列として50%の被弾率になる。

### 隊列の戦術的意味

- **前列**: 盾役。HPやDEFが高いゴブリンを配置
- **後列**: 火力役。被弾率が低いためATK重視のゴブリンを配置
- 味方は1列1体のため、パーティの順番＝隊列の前後

## 魔法システム

### 魔法一覧

| ID | 名前 | 威力倍率 | ターゲティング | チャージ数 |
|----|------|---------|-------------|----------|
| magic_arrow | マジックアロー | 0.8 | random_hits (3回) | 1 |
| fireball | ファイヤーボール | 1.2 | multi_target (6体〜) | 1 |

### ターゲティング方式

#### random_hits（マジックアロー型）

- hitCount回、生存敵からランダムに1体選んで攻撃
- **同じ敵に複数回命中**しうる
- 隊列の重み付けなし（完全ランダム）
- **必中**（命中判定なし）

#### multi_target（ファイヤーボール型）

- 最大hitCount体を選んでそれぞれ1回ずつ攻撃
- **重複なし**（Fisher-Yatesシャッフルで選出）
- 隊列の重み付けなし（完全ランダム）
- **必中**（命中判定なし）

### ターゲット数のレベルスケーリング

multi_target のターゲット数はレベルで増加:

```
hitCount = baseTargets + floor(level / scaleLevelInterval) × scalePerLevel
```

**ファイヤーボールの例**:

| レベル | ターゲット数 |
|--------|-----------|
| 1〜11 | 6体 |
| 12〜23 | 7体 |
| 24〜35 | 8体 |
| 36〜47 | 9体 |

### 魔法のダメージ計算

通常攻撃と同じ `DamageCalculator.calcDamage()` を使用:

```
魔法ダメージ = max(1, floor(ATK × spellPower × defMitigate × ... × (1 - damageReduction/100)))
```

- 通常攻撃との違いは `power` の値（マジックアロー: 0.8、ファイヤーボール: 1.2）
- 攻撃回数によるダメージ補正（getDamageModifier）は**適用されない**
- 被ダメージ軽減は適用される

### チャージシステム

- 各魔法は `defaultCharges`（デフォルト1）+ `extraCharges`（Mod等による追加）のチャージを持つ
- 1回使用するとチャージ-1
- **ターン10**: 全生存ユニットのチャージが+1回復（上限まで）

### 行動AI

```
魔法チャージあり → 魔法を使用（呪文リストの先頭から優先）
魔法チャージなし → 通常攻撃
```

魔法は通常攻撃より常に優先される。

## 種族システム

### 種族タグ

| 種族キー | 表示名 |
|---------|--------|
| goblin | ゴブリン |
| wolf | 狼 |
| bat | コウモリ |
| slime | スライム |
| skeleton | スケルトン |
| orc | オーク |
| troll | トロール |

- 味方ゴブリンは全員 `raceTags: ['goblin']` で統一（亜種による変化なし）
- 敵は種族に応じたタグを持つ

### 種族ボーナス

装備やバフに `raceBonus`（攻撃時の種族特効）や `raceTakenBonus`（被攻撃時の種族耐性）を設定可能。
現在の実装では使用されていないが、仕組みは完備されている。

```
攻撃側: raceFactor = (1 + 種族加算合計) × 種族乗算積
防御側: takenFactor = (1 + 被種族加算合計) × 被種族乗算積
```

## 戦闘結果

### BattleResult

| フィールド | 内容 |
|-----------|------|
| rounds | 実施ターン数 |
| outcome | `'win'` / `'lose'` / `'retreat'` |
| allyHPDelta | 各味方の（現在HP − 初期HP）。負数がダメージ |
| enemyDefeated | 倒した敵の数 |
| detailedLog | 全行動の詳細ログ |

### 終了条件

| 条件 | 結果 |
|------|------|
| 敵が全滅 | 勝利 (win) |
| 味方が全滅 | 敗北 (lose) |
| 20ターン経過 | 撤退 (retreat)（遠征では敗北扱い） |

### 遠征との統合

- `ExpeditionEngine.resolveCombat()` が `BattleSystem.executeBattle()` を呼び出す
- 戦闘結果の `allyHPDelta` がパーティメンバーのHPに反映される
- HP 0以下になったメンバーは戦闘不能（isKO, isDead）
- 撤退は遠征上では敗北として扱われる
