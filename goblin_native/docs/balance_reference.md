# バランス設計リファレンス

ゴブリンキングダムの戦闘バランスを「**対策の有無で勝率が二極化**する」という哲学のもと、シミュレータで検証可能な形で記述する。

## 1. 設計哲学

- **対策あり** → 勝率 80%+ で安定する。
- **対策なし** → 勝率は極めて低い。レベルを **+30〜40** 上げれば対策不要でクリア可能（ゴリ押し）。
- 「対策」とは攻略の知識：
  - ダメージ軽減%スキルが**同名で重複しない**ことを理解し、**別種のアーマーで複数積む**
  - 命中(`accuracy`)・攻撃回数(`attackCount`)を装備で確保し、確実に当てる
  - **隊列は1列1キャラ**。配列順 = 列番号で、前列ほど狙われる（`0.5^(row+1)` 重み）。耐久キャラを前、火力・補助を後ろに置く
  - 亜種（スライムゴブリン・ウルフゴブリン等）で最低クリアレベルを下げる
- 「面白さの源泉」は **攻略法の発見** であり、レベル上げは**保険**として機能する。

## 2. 難易度指標

各エリアに対して以下の指標を持つ。

| 指標 | 定義 | 用途 |
|---|---|---|
| **推奨レベル** | メカニクス理解（対策あり）でクリア可能な最低レベル。期待勝率 80%+ | UI / 攻略ガイド表示 |
| **ゴリ押しレベル** | 無対策（雑構成）でも勝率 80%+ になるレベル。**推奨レベル + 30〜40** | 内部テスト・シミュレータ検証用 |
| **最低クリアレベル** | 亜種・最適構成を全部嵌めれば勝てる最低レベル。期待勝率 80%+ | 上級者向け参考値 |

**良いバランス** =「**推奨Lv × 対策あり** ≧ 80%」かつ「**推奨Lv × 対策なし** ≦ 20〜30%」が同時成立する状態。

## 3. 4つの基準シナリオ

### 3.1 ゴブリン集落 (`goblin_village_1`)

- **areaLevel**: 10（個体値計算用なので難易度指標ではない）
- **推奨Lv**: 8〜10（暫定 / シミュレータで確定）
- **ゴリ押しLv**: 15〜20（暫定 / シミュレータで確定）
- **特徴**: チュートリアル相当。**対策不要でも勝てる緩さ** を持たせる。亜種があれば低レベルクリア可能。
- **対策の中身**:
  - 亜種（スライムゴブリン or ウルフゴブリン）を1体入れる
  - 標準ジョブで前衛配置
- **ボス**: ホブゴブリン（Lv15・HP150・Atk30、`survive_lethal_hp1` で1度耐える）

### 3.2 オーク野営地 1〜3 (`orc_camp_1` 〜 `orc_camp_1`)

- **areaLevel**: 20〜22
- **推奨Lv**: 22〜24（暫定）
- **ゴリ押しLv**: 55〜60（暫定）
- **特徴**: 装備理解の最初の壁。オークブルート(atk100)・オーク兵(atk70)に対し、**前衛の物理軽減%スキルを別種で重ねる** ことが必須レベルで効く。
- **対策の中身**:
  - 1列目に物理軽減%スキル付きアーマーを別種で2〜3個重ねる（`physical_reduction_*`）
  - 命中・攻撃回数を装備で確保（外しが致命的な手数差になる）
  - 後衛から雑魚（オーク兵）を散らす火力配置

### 3.3 ウルフ草原 (`wolf_grassland_1`)

- **areaLevel**: 34
- **推奨Lv**: 34〜36（暫定）
- **ゴリ押しLv**: 65〜75（暫定）
- **特徴**: ダイアウルフが `attackCount=4` で殴ってくる。**手数攻撃に対する耐久** が試される。
- **対策の中身**:
  - 物理軽減%・evasion・回復(クレリック)で被弾を吸収
  - 高 accuracy で確実に当てる（敵 evasion 46）
  - 隊列で被弾を分散（前列1体に集中させない）

### 3.4 vs討伐軍 (`subjugation_force_1`)

- **areaLevel**: 40〜44
- **推奨Lv**: 42〜44（暫定）
- **ゴリ押しLv**: 75〜85（暫定）
- **特徴**: 序盤の最難関。**全要素（ジョブ/亜種/隊列/装備）の運用最適化** が必要。
- **対策の中身**:
  - 騎士(def=50)を抜く火力（`physical_damage_*` 系で押し込む）
  - 魔術師・クレリックを後衛から先処理
  - 隊列補正で被弾コントロール
  - 装備tierを揃える

## 4. シミュレータによる検証

### 4.1 構成パターン

各エリアで以下のロードアウトを比較し、**80%勝てる最低レベル** を求める。

| ID | 名称 | 内容 | 期待結果 |
|---|---|---|---|
| **A** | 最適構成 | 1列目に物理軽減%を別種で重ね、命中・手数を装備で確保、隊列を理解した配置 | 推奨Lvで 80%+ |
| **B** | 軽減外し | 1列目から物理軽減%装備を全部外し、def/atk装備のみ | 推奨Lvで低勝率／+15Lv以上必要 |
| **C** | 隊列誤配置 | 1列目に低耐久キャラ（魔術師等）、前衛キャラを後ろに | 推奨Lvで低勝率／配置次第で +10Lv 必要 |
| **E** | 完全ゴリ押し | rank0装備のみ・対策ゼロ・無亜種 | ゴリ押しLv（推奨+30〜40）でようやく 80%+ |

### 4.2 入出力フォーマット

**入力**: `scripts/balance/scenarios/{areaId}.json`
- `areaId`, `levelRange{min,max,step}`, `iterations`, `loadouts[]`
- 各 loadout は `name`, `description`, `party[]`（配列順 = 隊列）

**実行**: `npm run sim:balance:reference -- --scenario {areaId}`

**出力**: 標準出力にレベル × ロードアウト勝率マトリクス、`--report tsv` で TSV、`--out` でファイル出力。

### 4.3 検証結果ログ

各エリアのパイロット結果は本ドキュメント末尾に追記する。推奨Lv／ゴリ押しLv の暫定値はパイロット結果で**書き換える**。

2. **物理軽減%は過剰対策**: A_optimal vs B_no_reduction で勝率差ほぼゼロ（Lv3-5 では B が A を僅かに上回る瞬間あり）。**ゴブリン集落帯ではタンクの素のHP/defで充分**。軽減%が決定的に効くのはオーク野営地以降と予想。
3. **隊列誤配置のペナルティ +3Lv**: C_misformation は Lv4 で 9%、Lv7 で 93%。**「タンクを前に置く」だけで +3Lv 早く攻略できる**。これはゴブリン集落帯でも明確に効く対策。
4. **亜種なしゴリ押しは +10Lv**: 通常ゴブリンだけでも装備対策抜きで Lv14。亜種2体 + 装備対策で Lv4 に短縮 = **亜種シナジーが +10Lv 短縮**の価値。当初の「+30〜40Lv」仮説は序盤エリアでは過大評価だった。

#### 次のアクション

- オーク野営地（`orc_camp_1`）のシナリオJSONを作成 → ここで初めて「物理軽減%」「隊列」が決定的に効くと予想。**A vs B、A vs C のレベル差が大きく出るはず**。
- vs討伐軍 まで揃えれば、エリア難易度の進行カーブが定量化できる。

#### 確定した指標

- **推奨Lv**: **Lv10**（areaLevelの **半分**）
- **ゴリ押しLv**: **Lv32**（推奨 +22Lv）
- **対策の効きの幅**: +22Lv（前回のゴブリン集落 +10 から大きく拡大）

#### 考察

1. **areaLevel に対する推奨Lvが想定より低い**: 仮説「推奨Lv=areaLevel+2 程度」は外れた。**areaLevel 20 のオーク野営地は、Lv10 で既に 96%** 勝てる。亜種3体+ホブゴブリンの inspire_150 で後列火力が +50% され、6人で速攻決着するため。
2. **物理軽減%は依然として過剰対策**: 12% スタックでも A=B=Lv10。**6人PTでは「殴り勝つ」が支配的で、軽減stackは活きない**。これはゴブリン集落・オーク野営地の両方で一貫した結論。軽減%が効くのは**長期戦（高HP単体ボス・耐久戦になる構造）**でないと駄目と推測。
3. **隊列誤配置のペナルティ +8Lv**: Lv10で4%、Lv16で63%、Lv18で82%。**「タンクを前に置く」だけで +8Lv 早く攻略できる**。ゴブリン集落（+3Lv）より影響が大きく、エリアが進むほど隊列の重要性が増している。
4. **亜種なしゴリ押しは +22Lv**: Lv32 で 99%。当初仮説「+30〜40Lv」より少し小さいが、想定の範囲内。

#### 設計に関する一貫した発見

- **「亜種＋隊列」が現状最強の対策軸**で、軽減%スキル系は二次的。
- **物理軽減stackは現バランスでは死んでいる**機能の可能性。長期戦設計のエリア（vs討伐軍 / 高難易度ボス戦）で活きるか要検証。
- **エリア進行に伴って対策の効きの幅が拡大**: ゴブリン集落 +10Lv → オーク野営地 +22Lv。順当な難易度カーブ。

#### 次のアクション

- ウルフ草原（`wolf_grassland_1`）：手数攻撃（attackCount=4-7）を相手にする。長期戦になる可能性が高く、**初めて軽減stackが効くかもしれない**シナリオ。
- vs討伐軍：序盤最難関の検証。

| ロードアウト | 80%勝率Lv | A比 |

#### 確定した指標

- **推奨Lv**: **Lv37**（areaLevel 34 + 3）
- **ゴリ押しLv**: **未達 / 不可能**（Lv75 でも rank0 装備のみでは 0%）
- **対策の効きの幅**: rank≤3 装備が**必須**

#### 考察

1. **rank0装備のみではクリア不可能**: E_brute_force は **Lv75 でも 0%**。ダイアウルフ HP440・ボス HP1010 を rank0武器（atk2-5）で削るのは事実上不可能。**ウルフ草原は「装備tier更新」が必須のエリア**。これはゴブリン集落・オーク野営地（レベル上げで突破可能だった）と質的に違う最初の壁。
2. **物理軽減stack 19% でも A=B**: Lv37 で A=89%, B=**94%**（B が A を上回る瞬間あり）。**実験設計の欠陥**：B_no_reduction でタンクから armor を外したが、代わりに装備した shield_mithril/shield_shield に `evasion_up_30/_20`、sword 系に `def_to_hp_X` が付いており、**別経路で防御が積めている**。「真の無防御」を測るには D_no_defense（武器だけ・装飾なし）が必要。
3. **隊列誤配置 +12Lv**: 拡大トレンド継続。ゴブリン集落 +3 → オーク野営地 +8 → ウルフ草原 +12。**「タンクを前」を守るだけでクリアLvが10Lv以上短縮**。
4. **手数攻撃に対する適応**: ダイアウルフ attackCount=4 への対処は、**ウルフ亜種の手数で速攻決着**（avg rounds 1-2 で決着）が解。タンクの長期耐久戦にはほとんどならない。

#### 設計に関する一貫した発見（更新）

- **エリア進行ごとの対策の効きの幅**: ゴブリン集落 +10Lv → オーク野営地 +22Lv → ウルフ草原 **+38以上（不可能）**。難易度カーブが指数的に拡大している。
- **ウルフ草原が初めて「装備更新必須」になる**：これまでは「レベルでゴリ押せる」が、ここから「装備tierがゲート」となる。
- **隊列の重要性は単調増加**: +3 → +8 → +12。
- **物理軽減%は依然として独立に効きを観測できていない**：実験設計の改善（D_no_defense ロードアウト追加）が必要。

### 5.4 vs討伐隊防衛戦・先遣隊 (`subjugation_force_1`)

**実行**: `npm run sim:balance:reference -- --scenario subjugation_force_1 --iterations 100 --level-min 15 --level-max 50`

- shield 系：`evasion_up_30/_40`（rank3〜4）、`breath_reduction_6/_7/_8`
- sword 系：`def_to_hp_3/_4/_5`（rank2〜4）

B のタンクは armor を捨てて shield×4 + sword×3 + gauntlet×2 を装備するため：
- evasion +90 以上スタック
- def→HP 変換が複数装備で大量
- 結果として armor 軽減stack 27% より総防御性能が高い

これは **物理軽減%スキル系の調整不足を示唆**。設計上、軽減%は装備の主軸的価値を持つはずだが、現状では shield/sword の付随スキルに負けている。

- ホブゴブリン前衛の `survive_lethal_hp1` がタンク代わりに被弾を吸収
- 6人PT で**前列1体への集中砲火が分散**される
- 速攻決着（avg rounds 1.5-2）で長期耐久が要らない

つまり**1体のタンクの装備の重要性は限定的**。隊列とパーティ構成（亜種、ジョブ、人数）の方が支配的。

### 6.2 ウルフ草原で軽減%が効いた理由

| 条件 | wolf_grassland_1 | 他エリア |

つまり**「軽減%が効くか」は敵側のスペック次第**：
- 敵 accuracy が低い → evasion(B) > reduction(A)
- 敵 accuracy が高い + attackCount 多 → reduction(A) > evasion(B)

### 13.4 観察

#### 1. ウルフ草原は -2Lv：プレイヤー側強化が支配

`goblin_binder`（ホブゴブリン Lv20 戦術、ゴブリン群を束ねるバフ）と `critical_support`（ライダー、味方クリティカル時に追撃）が効いた。F_with_cleric は Lv33→**Lv31** で 80% 到達、A_optimal も Lv35→**Lv33**。ウルフ草原は今回の更新で**むしろ簡単**になっており、設計上の想定（areaLevel 34 と推奨Lv 35 が拮抗）を踏まえると依然として「序盤の壁」として機能はしているが、**わずかに緩和**された。

#### 2. リザードマン沼砦 1/2 は +2Lv：`two_column_attack` の影響は限定的

`two_column_attack` 追加で +2Lv 程度の難化。**1段階分の難化**で、進行カーブの逆転問題は解消傾向だが完全ではない。なお C_misformation は liz_2/3 で **未達** に転じており（liz_2 は Lv59で71%、liz_3 は Lv64で45%）、隊列誤配置のペナルティはむしろ拡大している。

#### 3. **オーク砦 1 は +12Lv：5階拡張＋打ち合い＋トロル軽減の三重強化が決定的**

- **A_optimal**: Lv54 → **Lv66**（+12Lv）
- **F_with_cleric**: Lv44 → **Lv58**（+14Lv）
- **G/H ジョブのみ**: Lv62 → **Lv70**（+8Lv）

`counter_attack`（攻撃回数×0.3 で反撃、反撃にも反撃が発生）が前列火力 PT に対して最も刺さる。さらに5階拡張で平均敵数が増え、トロルの physical_reduction_5 が追加されたため、**亜種PTでもクレリック必須**の難易度に変化。F_with_cleric が A_optimal を **8Lv 早く** 80% 到達しているのが象徴的。

### 13.6 設計判断のポイント

1. **オーク砦が「ウルフ草原 → リザードマン沼砦」よりも明確に重い大ボス感**を獲得：areaLevel 55 のエリアで推奨 Lv66 は強気だが、5階構成・打ち合い反撃・トロル軽減の組み合わせは**「ここを越えると討伐軍だ」という最終試験感**を出している。
2. **F_with_cleric が orc_fortress_1 で唯一現実的なクリア手段**：A vs F の差が -8Lv まで開いた。**クレリックがほぼ必須化**しており、シーフ枠を1つ削ってでもクレリックを入れる構成が解になる。
3. **C_misformation が liz_2/3/orc_f で未達**：「タンクを前」の隊列ルールを破ると、もはやレベルでカバーしきれない難易度帯に入った。
4. **ウルフ草原の難易度緩和は意図か副作用かを判定する必要**：`goblin_binder`/`critical_support` を持たない初心者が触れる序盤エリアでもあるため、**プレイヤースキル取得タイミング次第で体感が変わる**。スキル無し前提で再シムする価値あり。
