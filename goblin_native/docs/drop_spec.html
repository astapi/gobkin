1. 全体フロー

戦闘勝利時に発生する報酬は 装備ドロップ・称号付与・因子ドロップ・ゴールド の4種類。下図は戦闘1回ぶんの処理順序。

2. 装備ドロップ仕様

ドロップは ノーマル（全敵）と レア（敵JSONの rareEquipmentDrops 配列）の2系統。両方とも同じ運乱数仕組みで当落を決め、ドロップ確定後に称号抽選を行う。

2.1 運乱数（共通基盤）

PT平均運値から運乱数 luckRoll を抽選。各判定ごとに振り直し。

2.3 レアドロップ rareEquipmentDrops

effectiveRare = rareMultiplier × rareDropMultiplierBoost rareThreshold = 100 − effectiveRare × 0.1 ドロップ条件: luckRoll > rareThreshold

敵の rareEquipmentDrops 配列のアイテムごとに判定する。係数 0.1 はノーマルの 10 の 1/100 で、デフォルト倍率では極めて低確率。

条件レアドロップ確率
rare=1.0, 運値0〜14≈ 0.09%
rare=1.0, 運値35+≈ 0.14%
rare=1.0, どんぐり×2 (effectiveRare=2), 運値35+≈ 0.29%

2.5 抑制要因

  • 遠征内の重複防止: 同じ templateId は1遠征で1回しか落ちない（droppedTemplateIds）。
  • Tier倍率はドロップ率に効かない: DUNGEON_TIER_SCALING.statScale は敵性能と報酬額のみで、装備ドロップ率には影響しない。
  • 低層ではRank 0固定: 敵Lv 1〜3 は Rank 0 しか出ない。

3. 称号付与仕様

装備ドロップが確定した後、各装備に対して 2段階 で称号を決定する。

抽選フロー
  1. 付与判定: 称号を付けるかどうかを運乱数で判定
  2. 種別抽選: 付与する場合、Tier 別の判定回数だけ称号テーブルを引いて、最も rank の高い称号を採用

4. 因子ドロップ仕様

因子は装備とは別系統。ボス戦勝利時のみ、生存メンバーごとに判定する。

4.1 判定式

probabilityMultiplier = (1 + bonusPercent / 100) × factorDropMultiplier × tierMultiplier 最終確率 = min(1, 敵JSONの probability × probabilityMultiplier) 判定: rng() < 最終確率
  • probability: 敵JSON で各因子に定義された基準確率（基準は 0.015 = 1.5%）
  • bonusPercent: スキルや装備による因子ドロップ率ボーナス
  • factorDropMultiplier: イベント／消費アイテム由来のブースト
  • tierMultiplier: ダンジョン Tier 別の倍率（下表）
  • 既所持の因子は除外される
  • 生存メンバーのみ判定対象
