# MODシステム

## 概要

Mod（モッド）はゴブリン誕生時にランダムに付与されるパッシブ効果。
各ゴブリンに0〜4個が付与され、ステータスのフラット加算・%増加・被ダメージ軽減を提供する。
個体値が高いほど強力なModが出現候補に含まれる。Modは後から変更・追加できない。

## 基本仕様

| 項目 | 値 |
|------|-----|
| 付与数 | 0〜4個（ランダム） |
| 付与タイミング | ゴブリン誕生時のみ |
| テンプレート総数 | 41個（prefix 36個 + suffix 5個） |
| グループ数 | 7種類 |
| Tier数 | 各グループ5〜6段階 |
| 同グループ排他 | 1グループにつき最大1個 |
| ダメージ軽減上限 | 75% |

## Modの種別

### prefix（ステータス増加系）

UIでは**青色バッジ**で表示。7グループ、各6 Tier = 42テンプレート。
UIでは**青色バッジ**で表示。6グループ、各6 Tier = 36テンプレート。

### suffix（軽減・特殊効果系）

UIでは**紫色バッジ**で表示。1グループ、5 Tier = 5テンプレート。

## Mod生成の仕組み

### 生成フロー

```
1. 生成数の決定
   0〜4の範囲でランダム（均等分布）
   ↓
2. 各Modの抽選（生成数ぶん繰り返す）
   ├─ 候補フィルタリング
   │   ├─ requiredIndividual <= ゴブリンの個体値
   │   └─ 同グループのModが未使用
   ├─ weight に基づく加重抽選
   └─ valueRange 内でランダムに値を決定
   ↓
3. グループを使用済みに登録
   → 同グループからは以後抽選されない
```

### シード値

```
modSeed = goblinId × 1000 + Date.now() % 1000
```

シード値ベースの擬似乱数生成器（線形合同法）を使用。同じシードなら同じModが生成される。

## Weight の傾向

グループごとに基本 Weight が異なり、出現しやすさに差がある:

| 出現しやすさ | グループ | Tier6 Weight |
|------------|---------|-------------|
| 最も出やすい | hp_flat, atk_flat, def_flat | 1200 |
| 出やすい | hp_percent, atk_percent, def_percent | 1000 |
| 最も出にくい | damage_reduction | 300（Tier5から） |

## ステータス計算への適用

### 計算式

```
実効値 = floor( (基礎 + 因子ボーナス + Modフラット + 装備フラット) × (1 + (Mod% + 装備%) / 100) )
```

### フラット vs パーセントの処理

| stat の末尾 | 処理 | 例 |
|------------|------|-----|
| `_flat` | 基礎ステータスにフラット加算 | hp_flat +10 → HP に +10 |
| `_percent` | 乗算係数に加算 | hp_percent +20 → HP が ×1.20 |
| `damage_reduction` | 別枠で集計（戦闘時に適用） | 後述 |

### 被ダメージ軽減の戦闘適用

```
最終ダメージ = max(1, floor(基本ダメージ × 攻撃回数補正 × (1 - 軽減率 / 100)))
```

- Modと装備の軽減値を合算し、上限75%でキャップ
- 最低ダメージは1（0にはならない）

**例**: 基本ダメージ100、軽減率30% → floor(100 × 0.7) = **70**

## Mod名の用途

テンプレートの `name` フィールド（「不滅の」「覇王の」等）は現在のUIでは**表示されない**。
UIではステータスラベル（HP, ATK等）と数値のみ表示される。
ゴブリンの名前にも付加されない。

将来的なMod説明表示やゴブリン二つ名システムへの拡張用として定義されている。

## UI表示

### ゴブリン一覧（GoblinCard）

全Modをバッジとして表示:

```
[HP+5%] [ATK+2] [被ダメ軽減+10%]
  青       青         紫
```

- **prefix**: 青バッジ（背景 #EFF6FF、枠 #BFDBFE、文字 #1D4ED8）
- **suffix**: 紫バッジ（背景 #F5F3FF、枠 #E9D5FF、文字 #6D28D9）

### ゴブリン詳細画面

Modセクションとしてステータスラベルと値を一覧表示:

```
Mod
  HP    +5%
  ATK   +2
  被ダメ軽減  +10%
```

### ステータスラベル対応

| stat | 表示ラベル |
|------|----------|
| hp_percent / hp_flat | HP |
| atk_percent / atk_flat | ATK |
| def_percent / def_flat | DEF |
| attackCount_flat | 攻撃回数 |
| accuracy_flat | 命中精度 |

## データ永続化

### DB保存形式

`goblins.mods_json` カラム（TEXT型）にJSON文字列で保存:

```json
[{"templateId":"hp_percent_t3","value":18},{"templateId":"atk_flat_t5","value":3}]
```

### ModInstance の構造

```typescript
interface ModInstance {
  templateId: string  // テンプレートID（例: "hp_percent_t1"）
  value: number       // 実際の値（valueRange 内でロール済み）
}
```

テンプレート情報（名前、group、stat等）は `modPool.json` から都度参照される。

## 型定義

### ModTemplate

```typescript
interface ModTemplate {
  id: string                    // "hp_percent_t1"
  name: string                  // "不滅の"
  group: string                 // "hp_percent"
  type: 'prefix' | 'suffix'    // バッジ色の区別に使用
  stat: ModStat                 // "hp_percent"
  tier: number                  // 1（最強）〜 6（最弱）
  valueRange: [number, number]  // [26, 30]
  weight: number                // 加重抽選の重み
  requiredIndividual: number    // 必要個体値
}
```

### ModStat（全17種）

フラット: `hp_flat`, `atk_flat`, `def_flat`
パーセント: `hp_percent`, `atk_percent`, `def_percent`
特殊: `damage_reduction`

※ 現在テンプレートが定義されているのは10グループのみ。attackCount, accuracy, evasion 系はテンプレート未定義。
