## 1. 既存ストーリーの問題点

### 良い点（残すべきもの）

先に、既に機能している部分を挙げます。改稿でもここは壊しません。

- プロローグ〜序盤（order 0〜11）の筆致。「殴られれば縮こまり、餌を投げられれば飛びつく」「先に歩いた仲間は、戻らないことがあった」など、具体的な動作で最弱集団の生活を見せる書き方は良い。
- 因子の群れへの波及描写（スライム因子→死ににくいゴブリンが生まれる）。ゲームシステムと物語が噛み合っている。
- 辺境の村陥落時の「これは、誰かの暮らす場所だった」。単純な征服譚にしないという設定方針が唯一実装されている箇所。
- 「人間側はまだ様子見している」という温度感（辺境城の静観）。世界が主人公中心に回っていないリアリティがある。

### 問題点A: 中盤以降、物語が「戦況報告」になる

order 13（討伐隊）以降、各話が 1 章だけになり、文体が「〜を制圧した。次は〜だ」というリザルト画面の要約になっています。

- 序盤にあった具体的ディテール（骨折した騎乗ゴブリン、鐘を鳴らす村人）が消える。
- 一人称も突然「我ら」「〜せねばならない」という軍記調に変わり、序盤の三人称マルク視点と不連続。
- プレイヤーが一番長く遊ぶ中盤〜終盤ほどテキストが薄い、という配分の逆転が起きている。

### 問題点B: 人間側に「顔」がなく、最終ボスが唐突

- 名前を持つ人間が一人もいない。辺境の城の指揮官も、討伐隊長も無名。
- エンディングで「勇者と人間王を打ち倒し」とあるが、**勇者はこの一文が初登場**。積み上げゼロで最終ボスが出て即退場するため、勝利のカタルシスがない。
- 「討伐される側から国を奪う側へ」というテーマは、人間側から見れば「魔王の誕生譚」。この鏡像構造（人間にとってマルクは魔王、勇者こそ主人公）は本作最大の武器になり得るのに、人間視点が一切ないため使えていない。

### 問題点C: 仲間に名前がなく、喪失も代償もない

- マルク以外のゴブリンが全員モブ。誰かが死んでも「戻らないことがあった」以上の重さが出せない。
- 主人公側が一度も本質的に負けない。犠牲を払う場面がないため、勝利が単調な右肩上がりになる。
- 因子にリスクがない。「敵の性質を取り込み続けるマルクは、まだゴブリンなのか?」という不安・代償が描かれず、設定上の「異常個体」の不気味さが活きていない。

### 問題点D: 全種族への対応が「制圧した」一色

意図は「協力したり倒したりして能力を得る」なのに、現状はアラクネ（盟約）以外ほぼすべて「制圧した/降した/屈服させた」で、サイドストーリーが金太郎飴化しています。

- ホビット「今は我らに従っている」、ドワーフ「鍛冶王を降した」、エルフ「攻略した」、ハーピィ「攻略した」——種族ごとの文化・交渉の違いが能力説明にしか反映されていない。
- 種族との関係バリエーション（同盟・取引・庇護・降伏・殲滅）を描き分ければ、それ自体が「ゴブリンの群れが国になっていく過程」の描写になるのに、その機会を捨てている。

### 問題点E: 中心の謎と伏線がない

- 「マルクはなぜ異常個体なのか」「因子とは何なのか」という物語の核となる謎に、本編が一度も触れない。引きがない。
- 拡張コンテンツ（魔王勢力）への伏線がゼロ。設定資料には「北方大山脈の先の魔族領は第二部の伏線として扱える」とあるのに未使用。
- エンディングが「王国の運営はこれからが本番だ」というゲームUIの説明のような文で終わり、物語的な余韻がない。

### 問題点F: データ・整合性のバグ（ストーリー以前の修正対象）

## 2. 改善方針

### 方針1: 語りを統一し、中盤以降を序盤と同じ密度に

全編を「三人称・マルク寄り視点、短い段落、動作で見せる」文体に統一。order 13 以降を各 2〜3 章に増量する。

### 方針2: 少数の名前つきキャラを置く

**ゴブリン側**（3体だけ。増やしすぎない）

- **ドマ**: プロローグで「戻らなかった仲間」に与える名前。マルクに木の実の割り方を教えた個体。マルクの原点となる喪失。
- **ギド**: 最古参の小柄なゴブリン。慎重派でマルクに悪態をつく相棒役。**討伐隊戦で戦死**し、中盤の折り返しに「勝利の代償」を刻む。
- **ラグ**: 無鉄砲な若い個体。最初に狼に乗って骨を折る奴。生き残り、終盤で最初にマルクを「王」と呼ぶ側になる。

**人間側**（鏡像構造の担い手）

- **ロラン**: オーク野営地でマルクたちを目撃して逃げた若い斥候。「あれは軍です」と最初に警告した男。討伐隊に従軍して敗走し、王都決戦まで生き延びるリカーリング敵。
- **グレアム辺境伯**: 辺境の城の老将。籠城でマルクを最後まで足止めした好敵手。
- **アレン**: 辺境の村の生き残りの少年。燃える村で折れた剣を拾ってマルクを睨む。王都で**勇者**として再登場する。「マルクが村を焼いたことが、勇者を生んだ」という因果を作る。

### 方針3: 「幕間（人間視点)」を3箇所挿入

村の陥落・討伐隊の敗北・王都決戦前夜の 3 点で、人間側の視点章を入れる。マルクたちが「魔物の群れ」から「軍」へ、「軍」から「王」へと**呼び名が変わっていく過程**を人間側の言葉で描く。マルクの王権は自称ではなく他称から始まる、という設定方針の実装。

### 方針4: 種族ごとに関係を描き分け、「国とは約束の束」というモチーフで貫く

| 種族 | 関係 | 交わす約束 |
| --- | --- | --- |
| ゴブリン集落 | 打倒→残党の吸収 | 「使い潰さない」（最初の約束） |
| オーク | 力による屈服 | 勝った者に従う |
| ウルフ | 共生 | 群れごと迎える |
| リザードマン | 降伏（沼の掟） | 沼を涸らさない |
| アラクネ | 試練と盟約 | 蜘蛛は森を出ない。糸と知恵を貸す |
| ハーピィ | 共闘（共通の敵） | 空を分け合う |
| ホビット | 庇護 | 丘を守る |
| ドワーフ | 取引 | 火を絶やさない |
| エルフ | 和解と警告 | （問いを持ち帰る） |
| トロル/ミノタウロス | 力比べで従える | 強さにのみ従う |
| ヴァンパイア | 殲滅 | なし（拒絶される側） |

アラクネ戦で女王に「奪われない巣が欲しい——それを人間の言葉で**国**と呼ぶ」と言語化させ、以後の各種族との約束が積み上がり、エンディングで「国とは約束の束だった」と回収する。

### 方針5: 因子の謎と魔族伏線を一本の糸にする

- 序盤: スライム因子取得時、マルクが自分の腕が一瞬形を失う感覚に怯える（代償の種）。
- 中盤: トロル因子で「痛みを忘れる群れはどこまでも進んでしまう」という怖さ。
- エルフ（サイド）: 「その力を北の果てで極めた者がいた。人間はそれを**魔王**と呼んだ」——因子の正体への最初の言及。
- ヴァンパイア: 灰になりながら「北の山の向こうで、同じ眼を見たことがある」——魔族領への具体的な伏線。
- ドラゴン: 「北の御方と同じ匂いがする」——最古の存在による裏付け。
- エピローグ: 北の空の赤、「——見つけた」という視線。拡張（魔王編）への引き。

### 方針6: ドラゴンの矛盾解消

「王家が建国時に**王都の地下深くの火脈**に封じた竜」とする。封印を解かれた竜は王都を焼かずに地下火脈の巣（=ダンジョン「ドラゴンの火山巣」）へ潜り、挑む者を待つ。ダンジョン名と整合し、「王家最後の切り札」設定も残る。

## 4. 拡張コンテンツ「魔王編」構想（概略）

本編で張った伏線（エルフの警告 / ヴァンパイアの灰の予言 / 竜の「北の御方」/ 禁書の署名 / エピローグの視線）を回収する第二部。

### 大筋

1. **使者**: 建国から間もなく、北方大山脈を越えて魔族の使者が来る。「北の御方が、お前を同胞として招いておられる」。マルクは断る——俺たちはもう、誰の下にもつかない。
2. **侵攻**: 魔王軍の先遣が旧人間領を襲い始める。人間の生き残り（東へ逃がした民、グレアム、そしてアレン）が難民としてゴブリンキングダムの境に押し寄せる。
3. **鏡像の反転**: かつて討伐される側だったマルクが、今度は「守る王」として人間を受け入れるかを問われる。勇者アレンとの停戦・共闘。「討伐される側から国を奪う側へ」の先にある「守る側」で本編テーマが完成する。
4. **因子の真相**: 魔王は「喰らう王」の完成形——因子を極め、他者を取り込み尽くし、約束を一つも持たない王。マルクの異常個体としての出自は魔王の因子の落し胤（風に乗って辺境に落ちた欠片）であることが示される。マルクと魔王は同じ力の、二つの答え。
5. **決戦**: 各種族との「約束の束」が連合軍として実体化する。蜘蛛の糸、ハーピィの空、ドワーフの武具、エルフの魔法、人間の騎士——本編で描き分けた関係が、そのまま戦力と物語の回収になる。

### 対比の軸

| | 魔王 | マルク |
| --- | --- | --- |
| 力 | 因子（同源） | 因子（同源） |
| 王のあり方 | 取り込み、使い潰す | 約束し、使い潰さない |
| 国 | 力の束 | 約束の束 |

北方山道 → 山脈の関門（魔族前哨）→ 凍土の廃都 → 魔王城外郭 → 魔王城・玉座（`docs/dungen_idea.md` の「亜空間の裂け目」「廃都の迷い路」は魔族領の番外として転用可能）。
