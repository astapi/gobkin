# Motion Inspector

ピクセルアートのモーションを、人間とCodexの両方が同じ画面で検品するためのローカルビューアです。追加依存はありません。

## 起動

```bash
npm run motion:viewer
```

`http://127.0.0.1:4178` を開きます。標準では次を読み込みます。

```text
artifacts/pixel-art-demo/game-base-goblin-motion-v2/strict64
```

画面上部の入力欄、またはURLの `?set=プロジェクト相対パス` で別セットへ切り替えられます。セット直下にはモーション別ディレクトリ、その中には `frame-1.png`、`frame-2.png` のような連番PNGを置いてください。

## 視認機能

- 最近傍拡大でのループ再生、速度・ズーム変更
- 再生停止、前後コマ送り、全フレーム一覧
- 接地線、バウンディングボックス、重心
- 前フレームのオニオンスキン
- 前フレームから変化したピクセルの強調
- シルエット表示と4種類の背景
- フレームごとの解剖学レビューと問題箇所マーカー

## 自動検品

- フレーム寸法の統一
- アルファ値が0/255の2値か
- 画像端への接触
- 接地Y座標の揺れ
- 重心移動量
- キャラクター面積に対する変更ピクセル量（待機の沸騰感検出）
- フレーム間の身長変化
- 最終フレームから先頭フレームへのループ差分

同じ結果を画面末尾の「Codex向け検品JSON」に出力します。視覚確認と数値確認を同じページで行えます。

## 解剖学レビュー

ピクセル統計だけでは、腕の二重化、欠損、誤った肩への接続などを確実に判定できません。そのため、セット直下の `motion-review.json` を必須の意味検品ゲートとして扱います。ファイルがなければ全フレームが `UNREVIEWED` となり、技術検品を通過していても全体は合格になりません。

各フレームでは、左右それぞれの `肩 → 肘 → 手` を独立して追跡します。腕や手の総数が2でも、同じ肩から2本伸びている場合は不合格です。脚、接地足、装備の握り、顔と体格の一貫性も同様に確認します。

レビューの状態は `pass`、`fail`、未記載の `unreviewed` です。`fail` には問題コード、説明、64x64座標系のマーカーを保存できます。現在のゴブリン歩行では2・4フレーム目を右腕二重化として登録しています。
